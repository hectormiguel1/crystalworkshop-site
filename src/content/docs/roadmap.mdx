## How reports are handled

Every problem report and feature suggestion goes through the same steps:

| Step | What it means |
|---|---|
| **New** | The report has arrived and nobody has looked at it yet. New reports are not listed here. |
| **Confirmed** | The problem is understood, or the idea is accepted for consideration. |
| **Planned** | It will be worked on. The release it is planned for is shown above. |
| **In progress** | Someone is working on it now. |
| **Fixed in *version*** | The fix ships in that version. Release cards and changelogs list it under "Fixed in this release". |

Only the number, title, product, step, planned release and date of an issue appear on this site. What you write in a report stays on the issue tracker.
