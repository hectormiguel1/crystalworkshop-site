Adds more accessory slots to FINAL FANTASY XIII: up to seven per character instead of four, with three new Crystarium accessory nodes per character that each add a slot.

Accessorize is set for each save slot, and it is **off** until you turn it on for the slot you play.

Want accessories with STR, MAG and HP stats and new auto-abilities? Add Accessories with Stats; it works with or without Accessorize.

## Features

- **Up to seven accessory slots per character.** The Equipment and Status screens show the extra slots.
- **New Crystarium accessory nodes.** Three new accessory nodes per character, next to each original accessory node, with that node's stage, role and CP cost. Each one adds a slot.
- **Clean saves.** Your save files only ever hold values the unmodded game accepts. The extra slots, the accessories in them and the new Crystarium nodes are kept separately for each save slot and come back when you load that slot.

## Requirements

- FINAL FANTASY XIII, Steam version, on Windows or on Linux (Proton).
- **PulseDepot** (beta), the mod manager. It also installs **Crux**, which loads this mod in the game and adds the in-game **Mod Settings** menu.

## Install

<Steps>

1. Download `xiii-accessorize-0.1.0.cws`.
2. In PulseDepot, select FINAL FANTASY XIII. Choose **Add mod…** and add the file.
3. Choose **Apply changes**.
4. Start the game from Steam as usual.

</Steps>

## Settings

Open **Configuration → Mod Settings → Accessorize**. Turn on **Enable Accessorize** for the save slot you play.

- With it off, the game plays as in the original.
- Turning it off for a save slot puts the accessories from the extra slots back in your inventory. They are put back on when you turn it on again.
- Your choice is stored with your next game save and comes back when you load that slot.

## Uninstall

In PulseDepot, choose **Remove from library**, then **Apply changes**.

Every save loads in the unmodded game, and the accessories that were in the extra slots are in your inventory.
