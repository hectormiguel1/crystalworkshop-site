Accessories in FINAL FANTASY XIII gain STR, MAG and HP stats that grow with their level, and there are new accessory auto-abilities.

Accessories with Stats works with or without Accessorize. Add Accessorize for up to seven accessory slots per character.

## Features

- **Accessory stats.** Accessories gain STR, MAG and HP stats that grow with their level.
- **New auto-abilities.** New accessory auto-abilities, named in all eleven game languages.
- **Works with or without Accessorize.** Add Accessorize for up to seven accessory slots per character.

## Requirements

- FINAL FANTASY XIII, Steam version, on Windows or on Linux (Proton).
- **PulseDepot** (beta), the mod manager. It also installs **Crux**, which loads this mod in the game and adds the in-game **Mod Settings** menu.

## Install

<Steps>

1. Download `xiii-accessories-with-stats-0.1.0.cws`.
2. In PulseDepot, select FINAL FANTASY XIII. Choose **Add mod…** and add the file.
3. Choose **Apply changes**.
4. Start the game from Steam as usual.

</Steps>

## Settings

Accessories with Stats has no in-game settings. It is always on while it is installed.

## Uninstall

In PulseDepot, choose **Remove from library**, then **Apply changes**.

Saves are never changed.
