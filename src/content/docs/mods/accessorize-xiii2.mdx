Gives every character in FINAL FANTASY XIII-2 seven accessory slots instead of four, with an optional accessory capacity bonus.

Accessorize is set for each save slot, and it is **off** until you turn it on for the slot you play.

## Features

- **Seven accessory slots.** The Equipment screen shows seven accessory rows. The capacity counter and the capacity check when you pick an accessory count all seven.
- **Automatic equipping.** Equipping automatically picks up to seven accessories that fit the capacity.
- **Capacity bonus.** An optional accessory capacity bonus (0 to 100, in steps of 5) for every character while the mod is on.
- **Extra slots count.** Accessories in slots 5 to 7 count in the field and in battle like the first four.
- **Clean saves.** Your save files only ever hold values the unmodded game accepts, and the accessory capacity in the save is always the game's own value; the bonus is never written. The extra slots and the accessories in them are kept separately for each save slot and come back when you load that slot.
- **Languages.** Menu texts in all eleven game languages.

## Requirements

- FINAL FANTASY XIII-2, Steam version, on Windows or on Linux (Proton).
- The Microsoft Store version is experimental and not tested yet.
- **PulseDepot** (beta), the mod manager. It also installs **Crux**, which loads this mod in the game and adds the in-game **Mod Settings** menu.

## Install

<Steps>

1. Download `xiii2-accessorize-0.1.0.cws`.
2. In PulseDepot, select FINAL FANTASY XIII-2. Choose **Add mod…** and add the file.
3. Choose **Apply changes**.
4. Start the game as usual.

</Steps>

## Settings

Open **Configuration → Mod Settings → Accessorize**. Turn on **Enable Accessorize** for the save slot you play, and set the **Accessory capacity bonus** if you want one.

- With it off, the game plays as in the original.
- Turning it off for a save slot puts the accessories from slots 5 to 7 back in your inventory. They are put back on when you turn it on again.
- Your choices are stored with your next game save and come back when you load that slot.

## Uninstall

In PulseDepot, choose **Remove from library**, then **Apply changes**.

Every save loads in the unmodded game, and the accessories that were in the extra slots are in your inventory.
