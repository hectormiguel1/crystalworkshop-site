Makes menus, icons and text crisper when FINAL FANTASY XIII runs above 1280x720. The game enlarges its menu art and text at higher resolutions; Crystal Clear keeps them crisp instead of blurry. At 1280x720 nothing changes.

## Features

- **Sharper menus, icons and text.** Art drawn at its own size, or smaller (UI scale below 100%), is left exactly as the game draws it. Art enlarged only a little is sharpened in proportion.
- **Art sharpness.** 0 to 100%, 50% by default. 0% only resamples; 100% is the crispest without halos around edges.
- **Text sharpness.** 0 to 100%, 50% by default. 0% leaves text as the game draws it.
- **Text style.** *Edge ramp*, the default, steepens the edges of each letter. *Smooth curve* raises the contrast of every letter pixel without halos.
- **Upscale filter.** *Edge-adaptive (FSR)*, the default; *Contrast-adaptive (CAS)*, which sharpens fine detail in the menu art with little halo (at 0% Art sharpness it only resamples); or *Bilinear (retail)*, which leaves the menu art exactly as the game draws it.
- **Texture-replacement packs.** Art the pack does not replace (battle HUD numbers, buttons, world map and others) is sharpened as normal, and replaced high-resolution art, drawn at or below its own size, is left as is.
- **Languages.** Setting names and descriptions in all eleven game languages.

## Requirements

- FINAL FANTASY XIII, Steam version, on Windows or on Linux (Proton).
- **PulseDepot** (beta), the mod manager. It also installs **Crux**, which loads this mod in the game and adds the in-game **Mod Settings** menu.
- The art sharpening needs DXVK or a modern GPU. Otherwise the art stays as in the retail game and only text is sharpened.

## Install

<Steps>

1. Download `crystal-clear-0.1.0.cws`.
2. In PulseDepot, select FINAL FANTASY XIII. Choose **Add mod…** and add the file.
3. Choose **Apply changes**.
4. Start the game from Steam as usual.

</Steps>

## Settings

Open **Configuration → Mod Settings → Crystal Clear**.

| Setting | Default | Effect |
|---|---|---|
| Sharper interface | On | Turn off to get the retail look back |
| Art sharpness | 50% | How strongly menu artwork is sharpened |
| Text sharpness | 50% | How strongly text edges are sharpened |
| Text style | Edge ramp | Edge ramp or Smooth curve |
| Upscale filter | Edge-adaptive (FSR) | Edge-adaptive (FSR), Contrast-adaptive (CAS) or Bilinear (retail) |

## Compatibility

- Works alongside the Honey, I Shrunk the HUD mod.

## Uninstall

In PulseDepot, choose **Remove from library**, then **Apply changes**.
