## What the values mean

- **Supported (tested in game):** works, and has been checked by playing the game.
- **Supported:** works and passes automated checks.
- **Experimental:** may work, but has not been tested in game. Expect problems, and please report what you find.
- **Not supported:** does not work with this version.

## Microsoft Store versions

- Only FINAL FANTASY XIII-2 from the Microsoft Store is experimental. Nothing has been tested in game on any Microsoft Store version yet.
- CrystalWorkshop does not find a Microsoft Store install by itself: choose the game folder yourself.
- PulseDepot can install mods for it, but cannot start Microsoft Store games yet. Start the game from the Microsoft Store or Xbox app.
- FINAL FANTASY XIII and LIGHTNING RETURNS from the Microsoft Store are not supported.

If you try the Microsoft Store version of XIII-2, please report the result, whether it works or not. Say in the report that you use the Microsoft Store version, and attach the [Crux log](../crux/logs/) if there is one.
