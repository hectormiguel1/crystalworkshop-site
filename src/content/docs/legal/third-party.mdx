The packages include third-party components under their own licences, and those licences apply to those components instead of the freeware terms. Among them: Vineflower (Apache-2.0, shipped unmodified and run as a separate program), DXVK (zlib, Windows CrystalWorkshop package), the Inter and JetBrains Mono fonts (SIL OFL 1.1), and the MinGW-w64 and GCC runtimes of the Windows builds. No Java runtime (JDK) is bundled.

Filter by package or licence, or search by name. Each package's `THIRD-PARTY-NOTICES.txt` has the full licence texts.
