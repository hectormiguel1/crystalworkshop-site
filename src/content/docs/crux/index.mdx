**Crux** is the mod host loaded by the game. While you play, it:

- serves the files of the **Crux image** (`active.crximg`, the one file PulseDepot merges from every enabled mod) to the game, so the game's own archives stay untouched;
- loads the mods' native code units;
- keeps each mod's settings in its own storage, `mod-state.dat` in the mod folder, per save slot. Your saves are never read or written.

You do not install Crux by hand: [PulseDepot](../pulsedepot/) ships both builds and installs the right one when you apply, after checking its SHA-256.

## Two builds

| Build | File | Where it goes | When |
|---|---|---|---|
| NovaFix addon | `Crux.dll` | the NovaFix `addons` folder (NovaFix loads `addons\*.dll`) | NovaFix is installed |
| Standalone | `version.dll` | beside the game executable; it forwards every call to the system's `version.dll` | no NovaFix |

Both are 32-bit, like the games. Installing one removes the other, so only one Crux runs. [Standalone or NovaFix addon](hosts/) explains how PulseDepot chooses.

## Which games

| Game | Addon folder | Standalone folder |
|---|---|---|
| FINAL FANTASY XIII | `white_data\prog\win\bin\addons\` | `white_data\prog\win\bin\` |
| FINAL FANTASY XIII-2 | `alba_data\prog\win\bin\addons\` | `alba_data\prog\win\bin\` |
| LIGHTNING RETURNS | — | the game folder |

LIGHTNING RETURNS support is experimental: no LR mods ship with this release.
