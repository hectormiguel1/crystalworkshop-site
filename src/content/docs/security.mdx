Every download on this site, and the programs and DLLs inside the app packages, is checked with two online multi-engine scanners, [VirusTotal](https://www.virustotal.com/) and [MetaDefender](https://metadefender.com/), when a release is published and again every week. This page lists the latest result for each file, a link to the full report and the file's SHA-256, so you can check it yourself.

## Reading the results

- **VirusTotal 0/72**, for example, means none of the 72 engines that gave a verdict flagged the file. Engines that do not support the file type are not counted.
- **MetaDefender 0/21** reads the same way for MetaDefender's engines.
- **In progress**: the file was submitted and the results are not in yet. **Not set up** or **not scanned yet**: there is no automatic result for that scanner; the "Scan it yourself" links still work.
- The report link shows every engine's verdict and the date of the scan.

## Why a few engines may flag these files

CrystalWorkshop, PulseDepot and Crux are free tools that are not code-signed. Some engines rate unsigned programs from small publishers as suspicious by heuristics, that is by how a program looks rather than by a known threat. The standalone Crux build is a `version.dll` that sits beside the game executable, so Windows loads it together with the game. Malware uses the same loading technique, so some engines flag any `version.dll` that does not come from Microsoft.

A result from one to three engines with generic names (words like *Heur*, *Generic*, *ML*, *Suspicious* or *Unsafe*) is usually such a false positive. Many engines agreeing on one named threat is not, and neither is a file whose SHA-256 differs from the one listed here: in either case, do not run the file, and report it.

## Check a download yourself

1. **Compare the SHA-256.** After downloading, compute the file's SHA-256 and compare it with the value on the [Downloads](../downloads/) page and below. Every character must match.
   - **Windows (PowerShell):** `Get-FileHash .\file.zip`
   - **Linux:** `sha256sum file.zip`
2. **Look the SHA-256 up.** The **Scan it yourself** links under each file search VirusTotal, MetaDefender, Jotti and Hybrid Analysis for that SHA-256. A lookup uploads nothing. If a service does not know the file yet, you can upload the file to it yourself.
3. **Check the extracted files.** The programs and DLLs inside the PulseDepot and CrystalWorkshop packages are listed on their own, so you can also compare what you extracted.

## Report a concern

If a scanner names a threat, or a SHA-256 does not match, open a problem report for the app or mod the file belongs to{repoUrl ? <> (<a href={`${repoUrl}/issues/new/choose`} rel="noopener">choose a form on GitHub</a>)</> : null}. Include the file name, the version, the SHA-256 you got and the link to the scan report. Every release card and mod page also has a **Report a problem** button that fills in the version for you.
