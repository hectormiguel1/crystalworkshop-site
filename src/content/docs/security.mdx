Every download on this site, and the programs and DLLs inside the app packages, is checked when a release is published and again every week with two online multi-engine scanners, [VirusTotal](https://www.virustotal.com/) and [MetaDefender](https://metadefender.com/), with the [Kaspersky Threat Intelligence Portal](https://opentip.kaspersky.com/), and with two sandboxes that run the file and rate what it does: [Hybrid Analysis](https://hybrid-analysis.com/) and [Triage](https://tria.ge/). This page lists the latest result for each file, a link to the full report and the file's SHA-256, so you can check it yourself.

## Reading the results

- **VirusTotal 0/72**, for example, means none of the 72 engines that gave a verdict flagged the file. Engines that do not support the file type are not counted.
- **MetaDefender 0/21** reads the same way for MetaDefender's engines.
- **Kaspersky: clean** is Kaspersky's verdict for the file: *clean*, *adware or other*, *malware*, or *no verdict* when Kaspersky has no data on it yet.
- **Hybrid Analysis** and **Triage** are sandboxes. Hybrid Analysis gives a verdict (*no specific threat*, *suspicious* or *malicious*) and a threat score out of 100; Triage gives a score from 1 (nothing malicious seen) to 10 (known malware). Sandboxes rate behaviour, so tools that read and write game files can score above the minimum without being harmful.
- **More from VirusTotal** under a file lists extra details when VirusTotal has them: the most common threat label, sandbox verdicts, matching community YARA and Sigma rules, the code signature, and the behaviours and MITRE ATT&CK techniques its sandboxes saw.
- An engine result marked **heuristic (machine-learning) — no signature match** comes from a model that rates how a file looks, or from a reputation label for a file it has rarely seen, not from a match with known malware.
- **In progress**: the file was submitted and the results are not in yet. **Not set up** or **not scanned yet**: there is no automatic result for that scanner; the "Scan it yourself" links still work.
- The report link shows every engine's verdict and the date of the scan.

## Why a few engines may flag these files

CrystalWorkshop, PulseDepot and Crux are free tools that are not code-signed. Some engines rate unsigned programs from small publishers as suspicious by heuristics, that is by how a program looks rather than by a known threat. The standalone Crux build is a `version.dll` that sits beside the game executable, so Windows loads it together with the game. Malware uses the same loading technique, so some engines flag any `version.dll` that does not come from Microsoft.

A result from one to three engines with generic names (words like *Heur*, *Generic*, *ML*, *Suspicious* or *Unsafe*) is usually such a false positive. Many engines agreeing on one named threat is not, and neither is a file whose SHA-256 differs from the one listed here: in either case, do not run the file, and report it.

At the moment, Microsoft Defender reports `Trojan:Win32/Wacatac.C!ml` for the Windows programs and for `Crux.dll`; no other engine reports it. The `!ml` ending marks a machine-learning guess, which Defender often makes for new, unsigned files, not a match with known malware. It has been reported to Microsoft as a false positive.

## Check a download yourself

1. **Compare the SHA-256.** After downloading, compute the file's SHA-256 and compare it with the value on the [Downloads](../downloads/) page and below. Every character must match.
   - **Windows (PowerShell):** `Get-FileHash .\file.zip`
   - **Linux:** `sha256sum file.zip`
2. **Look the SHA-256 up.** The **Scan it yourself** links under each file search VirusTotal, MetaDefender, Kaspersky, Jotti, Hybrid Analysis, Triage and Filescan.io for that SHA-256. A lookup uploads nothing. If a service does not know the file yet, you can upload the file to it yourself.
3. **Check the extracted files.** The programs and DLLs inside the PulseDepot and CrystalWorkshop packages (including the DXVK `d3d9.dll` that comes with CrystalWorkshop) are listed on their own, so you can also compare what you extracted.
