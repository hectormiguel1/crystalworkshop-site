## Create package

**Create package** builds a CrystalWorkshop Shard from a folder of changed files: Nova Chrysalia-style `Data/`, `EN-Data/`, `JP-Data/`, NCCP code patches, or an external installer, plus metadata and artwork. It compares the folder with your own game files, so it needs the game folder. Most authors should build shards in [CrystalWorkshop](../../crystalworkshop/first-mod/) instead.

![Create package](../../../assets/shots/pd/create.webp)

## Format tools

**Format tools** extracts or converts single files into a separate workspace and never writes into the game. It handles:

- WPD / WDB / XGR / record packs;
- ZTR ↔ JSON or Nova Chrysalia TXT;
- filelists;
- White archives;
- TRB/IMGB;
- SCD ↔ Ogg/WAV;
- WDB ↔ `.xlsx` or SQLite.

![Format tools](../../../assets/shots/pd/tools.webp)
