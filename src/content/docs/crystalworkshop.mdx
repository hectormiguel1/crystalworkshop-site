CrystalWorkshop is a modding editor for the PC (Steam) releases of
FINAL FANTASY XIII, XIII-2 and LIGHTNING RETURNS. It reads your installed
game, lets you change its data, text, models, effects, scenes and scripts,
and packs your changes into a **CrystalWorkshop Shard** (`.cws`). Players
install that shard with **PulseDepot**.

:::caution[ALPHA 0.1.0]
Expect rough edges. Pages mark **Experimental** features
and per-game limits. Keep backups of your mod projects. CrystalWorkshop
never writes save files. It writes into the game folder only when you
&#101;xport loose files, and only to `mod_data` and `ff13_studio`.
:::

## Getting started

1. [Installing](installing/): Windows and Linux packages and what they need.
2. [First Run and Game Setup](first-run/): open your game.
3. Try a task:
   - [Simple DB Edit](db-edit/): change an item price in a sheet and with SQL.
   - [ZTR Text Edit](ztr-text-edit/): change in-game text, with its control tags.
   - [Model Edit](model-edit/): inspect a character model, its textures and materials.
   - [VFX Edit](vfx-edit/): browse an effect, change a field, swap a reference, play it.
   - [Scene Edit](scene-edit/): move, add and delete placements in a zone (LYB).
   - [Crystarium Edit](crystarium-edit/): change Crystarium nodes (XIII).
   - [Scripts Actions and Sound](scripts-actions-and-sound/): CLB Java scripts, ACB schedules, events, sound.
4. [Simple Mod Export](mod-export/): turn your changes into a `.cws` shard and install
   it with PulseDepot.
5. [Enabling MCP](mcp/): let an AI client (Claude Code, Claude Desktop, Codex)
   use the same editors.

## Native extensions (developers)

A shard can also carry **extension units**: small native DLLs that Crux
loads into the game, for hooks, in-game settings pages and state that
follows your save slot. Write them in Rust with the open-source extension
SDK ([workshop-extension-sdk on GitHub](https://github.com/hectormiguel1/workshop-extension-sdk),
MIT or Apache-2.0), then add the DLL on the **Project** page and export the
shard as usual. The
[Extension SDK guide](https://hectormiguel1.github.io/crystalworkshop-site/sdk/)
covers it step by step.

## What works where

| Area | XIII | XIII-2 | LR |
|---|---|---|---|
| Sheets (WDB) + SQL | yes | yes (record packs) | yes (record packs) |
| Text (ZTR) | yes | yes | yes |
| Models (inspect, textures, render) | yes | yes; writes unverified | yes; writes unverified |
| VFX tree, playback, reference swaps | yes | read-only fields | read-only fields |
| Scene editor (View, gizmo, add/duplicate/delete) | yes | Experimental | Experimental |
| Crystarium | yes | — | — |
| Scripts (CLB Java) | yes | browse | browse |
| Battle page | yes | — | — |
| Shard export verified in game | yes | unverified routes need consent | unverified routes need consent |

The [feature status](feature-status/) page lists each feature as Completed,
Experimental or Known gap.
