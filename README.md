# CrystalWorkshop site

The public release and documentation site for CrystalWorkshop, PulseDepot,
Crux and the mods: Astro + Starlight, static, with Pagefind search.

```sh
npm ci
npm run dev                      # local preview
RELEASE_DIR=../dist/release-YYYY-MM-DD npm run build
npm run check                    # internal links + banned terms on the build + issue forms
npm test                         # unit tests (node test runner)
```

- Feedback: `scripts/lib/feedback.mjs` builds the issue forms, labels and the
  prefilled "Report a problem" / "Suggest a feature" links;
  `scripts/status.mjs` turns issues and milestones into `api/status.json`
  and `api/roadmap.json` for the Roadmap page. See `deploy-template/README.md`
  section 6.
- Banned names (people and their tools) are matched by SHA-256 in
  `scripts/lib/terms.mjs`; they are never written in plain text here.

- `scripts/generate.mjs` turns the release folder and the docs into
  `src/data/*.json`, the generated pages (CrystalWorkshop wiki, mod pages,
  PulseDepot complete guide), images and `public/legal`, `public/og`.
  Generated pages start with a "Generated by scripts/generate.mjs" comment:
  edit their sources, not the pages.
- Hand-written pages: home, downloads, changelog, the PulseDepot step
  guides, the CrystalWorkshop "Build your first mod" track, Crux and legal.
- Screenshots of the apps live in `src/assets/shots/` (re-shot from the
  real UI in an isolated game root); they replace a wiki image with the
  same name.
- Build output: `../dist/site` inside the private repository, `./dist`
  elsewhere (`SITE_OUT_DIR` overrides).

Publishing: see `deploy-template/README.md`.
